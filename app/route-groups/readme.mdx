# 路由组

路由组可用于：

- 将路由段从共享布局中排除。
- 在不影响URL结构的情况下组织路由。
- 通过划分应用程序的顶级层级创建多个根布局。

### 示例

- 本示例通过路由组为应用不同板块创建布局：
  - (main)：主共享界面
    - (shop)：电商专用共享界面
    - (marketing)：营销专用共享界面
  - (checkout)：排除主共享界面的顶级组
- 请尝试浏览页面，观察各板块使用的不同布局。
