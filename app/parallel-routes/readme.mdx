# 并行路由

- 并行路由允许您在同一布局中同时或有条件地呈现多个页面，且各页面拥有独立导航。
- 并行路由可用于实现高级路由模式，例如[条件路由](https://nextjs.org/docs/app/building-your-application/routing/parallel-routes#conditional-routes)和[拦截路由](https://nextjs.org/docs/app/building-your-application/routing/intercepting-routes)。
- 尝试使用某条并行路由中的标签页进行导航。注意URL会发生变化，但未受影响的并行路由仍保持原状。
- 尝试使用浏览器的后退/前进导航功能。注意浏览器的URL历史记录状态和活动UI状态均能正确同步。
- 尝试导航至某并行路由的标签页后刷新浏览器。注意可选择显示哪些UI来呈现与初始URL不匹配的并行路由。
