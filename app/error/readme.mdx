# Error.js

`error.js` 是一种文件规范，用于为路由段定义在发生意外运行时错误时显示的备用界面。

当路由段或其子节点抛出错误时，将渲染来自 `error.js` 的备用界面。应用程序其余部分保持交互性，用户可尝试重置或恢复错误。

通过文件系统层级定义不同粒度的备用界面。

### 演示

- 浏览分类目录，在嵌套布局中触发错误
- **错误隔离机制**：错误边界将意外运行时错误限制在所属路由段内，防止其影响应用其他部分
