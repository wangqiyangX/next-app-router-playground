# !!col

- 通过在函数定义顶部添加 `use cache` 指令，将单个 React 服务器组件标记为可缓存。
- 当可缓存组件被调用且输入相同时，若存在缓存结果则直接复用，否则渲染并缓存输出结果。

### 演示

- 产品列表组件被标注了 `use cache`。
- 添加了人为设置的一秒延迟，以便更明显地体现差异。
- 由于该组件可缓存，延迟仅在组件首次渲染时发生。
- `layout.tsx` 和 `page.tsx` 未显式添加 `use cache` 注解，但 Next.js 通过检测其未使用任何动态 API 推断为静态组件。若后续引入动态操作，Next.js 将引导开发者添加 `use cache` 或 `<Suspense>` 边界组件。

### 注意事项

- 此演示使用了实验性的 `use cache` 指令，并描述了稳定后缓存行为。
