# 客户端上下文

将组件导入标记为`'use client'`的文件中，该组件将成为客户端程序包的一部分。这意味着您无法将服务器组件导入客户端组件。
但是，您可以将服务器组件作为 prop（或子组件）传递给客户端组件。这使您可以在客户端渲染的 UI 中可视化地嵌套服务器组件。

通过这种模式，您可以将客户端上下文提供程序放置在树的高处，并仍然在其中嵌套服务器组件。更深层次的客户端组件可以访问共享上下文，即使它们之间有服务器组件。
