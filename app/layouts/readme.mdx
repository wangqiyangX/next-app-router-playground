# 嵌套布局

布局是多个路由共享的用户界面。在导航过程中，布局会保留状态、保持交互性且不会重新渲染。

### 演示

1. 尝试在上方导航栏中切换类别与子类别。
2. 注意在同级路由间导航时，布局不会重新渲染（视觉表现为粉色边框动画渐变为灰色）。
3. 注意客户端状态（点击计数器可视化呈现）在导航间得以保留。
4. 注意在同级路由加载时，仍可与布局进行交互（例如点击计数器）。
