# Loading.js

`loading.js` 是一种文件规范，用于为加载中的路由段定义备用界面，从而实现动态路由的预加载和即时导航。

当用户导航至带有预加载备用界面的动态路由时，URL会立即更新，并在加载过程中显示加载状态。

通过文件系统层级结构可定义不同精度的备用界面。

### 演示

- 使用上方菜单在分类间导航。
- **即时导航**：即使新路由段仍在服务器端渲染，我们也能即时导航（更新URL并渲染备用界面）至新路由。实际内容将在渲染完成后流式加载。

#### 注意事项

- 页面添加了人工延迟以模拟数据请求缓慢，使加载状态更明显。
