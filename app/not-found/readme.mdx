# 未找到

`not-found.js` 是一种文件约定，用于在抛出 `notFound()` 函数或访问未匹配 URL 时，为路由段定义备用界面。

通过文件系统层级结构，可定义更具体或更通用的备用界面。

### 演示

- 访问不存在的类别或子类别：

  - [不存在的子类别](/not-found/electronics/does-not-exist)
