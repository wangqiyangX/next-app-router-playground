通过在 `layout.tsx` 或 `page.tsx` 文件顶部添加 `use cache` 指令，将路由段标记为可缓存。

# !!col

```tsx app/page.tsx
// !mark
'use cache';

  // ...
}
```

#### 在客户端

- 路由器首先检查客户端缓存中是否存在有效的缓存条目，然后才向服务器发出新请求。
- 服务器响应中的缓存条目会更新客户端缓存。

#### 预渲染

- 可缓存的路由段可以提前进行预渲染，既可以在构建时，也可以在后台重新验证期间进行。
- 预渲染的结果会分发到全球内容分发网络（CDN）。
- 在运行时，CDN 会向客户端提供最近的静态结果。
- `layout.tsx` 和 `page.tsx` 是独立可缓存的。这意味着 `layout.tsx` 可以预渲染，而其 `page.tsx` 可以在请求时动态渲染。

### 演示

- 在 `page.tsx` 中添加了人为的一秒延迟，以使差异更加明显。

  ```tsx app/page.tsx
  'use cache';

  export default async function Page() {
    // !mark
    await new Promise((resolve) => setTimeout(resolve, 1000));

    const products = db.product.findMany();
    // ...
  }
  ```

- 由于整个路由是可缓存的，因此此延迟仅在函数首次运行时发生，即在预渲染期间。

### 注意事项

- 此演示使用了实验性的 `use cache` 指令，并描述了稳定后缓存行为。
