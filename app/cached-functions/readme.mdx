### 演示

- 获取产品列表的数据获取函数已添加 `use cache` 注解。
- 为使差异更明显，该函数中添加了人为设置的一秒延迟。
- 由于该函数可缓存，延迟仅在首次调用时发生。
- `layout.tsx`、`page.tsx` 和 `<ProductList>` 未显式添加 `use cache` 注解，但 Next.js 通过检测其未使用任何动态 API 推断为静态组件。若后续引入动态操作，Next.js 将引导开发者添加 `use cache` 或 `<Suspense>` 边界组件。

### 注意事项

- 此演示使用了实验性的 `use cache` 指令，并描述了稳定后缓存行为。
